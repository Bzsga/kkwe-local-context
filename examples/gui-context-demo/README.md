这是 **2026-10-28 的已编译演示成品**，保留 7 个可展开的普通 GUI 触发器。它用于阅读测试逻辑和复现当时的验证场景；重玩这份成品不会重新验证当前仓库的新版源码。

## 使用

1. 使用受支持的 KKWE 打开地图，按 **F4** 查看触发器。建议从 `Demo_00_Start` → `Demo_00_OneRound` 阅读。
2. 在 Warcraft III 中运行地图后，测试会自动执行两轮；游戏内输入 `-demo` 可重跑。
3. 验证当前工具版本时，先按[仓库说明](../../README.md#安装)安装或启用修复，再将演示图**另存为新文件**并运行。只更新电脑上的工具，不会改变原有 `.w3x` 已编译进去的运行库。

当时的实机环境为 Warcraft III 1.27a。打开、重新保存需要相应 KKWE 的 GUI 动作定义；本仓库不附带编辑器或游戏。
